# Science Competitions Insight (SCI)

A project for discovering and managing science and technology competitions. This `main` branch is a navigation entry point and contains no application code.

## Branch guide

| Branch | Contents |
| --- | --- |
| [demo](https://github.com/nhandz2008/sci-project/tree/demo) | FastAPI backend, Vite/React frontend, deployment scripts and monitoring. |
| [dev](https://github.com/nhandz2008/sci-project/tree/dev) | FastAPI backend and Next.js frontend with development tooling. |
| [backend](https://github.com/nhandz2008/sci-project/tree/backend) | Full-stack snapshot with backend upload work and tests. |
| [frontend](https://github.com/nhandz2008/sci-project/tree/frontend) | Full-stack snapshot with frontend interface work. |
| [frontend_fix](https://github.com/nhandz2008/sci-project/tree/frontend_fix) | Same starting snapshot as frontend at the time of this review. |
| [configs](https://github.com/nhandz2008/sci-project/tree/configs) | Development plans, implementation notes, and editor rules. |
| [deprecated-backend](https://github.com/nhandz2008/sci-project/tree/deprecated-backend) | Earlier backend implementation. |
| [deprecated-frontend](https://github.com/nhandz2008/sci-project/tree/deprecated-frontend) | Earlier standalone Next.js frontend. |
| [deprecated-cursor-config](https://github.com/nhandz2008/sci-project/tree/deprecated-cursor-config) | Earlier documentation and editor rules. |

## Getting started

Check out the branch you intend to work on, then follow its README. The branches contain different implementations; their setup commands and dependencies are not interchangeable. There is no build or test command on `main`. No branches are merged or removed by this documentation update.
